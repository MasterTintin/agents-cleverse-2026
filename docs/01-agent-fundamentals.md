# บทนำ (Introduction)

ในช่วงไม่กี่ปีที่ผ่านมา เราได้เห็น AI อย่าง ChatGPT, Claude และ Gemini เข้ามามีบทบาทในชีวิตประจำวันมากขึ้น หลายคนจึงเริ่มคิดว่า AI เหล่านี้คือ **AI Agent**

แต่ในความเป็นจริงแล้ว **Large Language Model (LLM)** และ **AI Agent** ไม่ใช่สิ่งเดียวกัน
LLM เปรียบเสมือน **สมอง (Brain)** ที่สามารถเข้าใจภาษา วิเคราะห์ และสร้างข้อความได้

ส่วน AI Agent คือ **ระบบ (System)** ที่นำ LLM มารวมกับองค์ประกอบอื่น ๆ เช่น Memory, Tools, Planning และ Runtime เพื่อให้สามารถลงมือทำงานและบรรลุเป้าหมายได้

กล่าวอีกอย่างหนึ่ง

> **AI Agent คือวิวัฒนาการจาก "การตอบคำถาม" ไปสู่ "การลงมือทำงาน"**

หลังจากอ่านบทนี้ เราควรสามารถตอบคำถามต่อไปนี้ได้

# 1. AI Agent คืออะไร?

สมมติว่าเราถาม ChatGPT ว่า

> "ช่วยสรุปไฟล์ report.pdf ที่อยู่ในเครื่องให้หน่อย"

ChatGPT จะตอบประมาณว่า

> "กรุณาอัปโหลดไฟล์"

เนื่องจากมันไม่สามารถเข้าไปเปิดไฟล์ในเครื่องของเราเองได้

แต่ถ้าเป็น AI Agent

มันจะคิดเป็นขั้นตอน

Goal
↓
ค้นหาไฟล์ report.pdf
↓
เปิดไฟล์
↓
อ่านข้อความ
↓
สรุปเนื้อหา
↓
ตอบผู้ใช้

สังเกตว่า Agent ไม่ได้รีบตอบทันที

แต่มันจะ

- คิด (Reason)
- วางแผน (Plan)
- ลงมือทำ (Act)
- ตรวจสอบผลลัพธ์ (Observe)

จนกว่าจะทำงานสำเร็จ

---

## Definition

AI Agent คือ

> **ระบบซอฟต์แวร์ที่สามารถรับเป้าหมาย วิเคราะห์ปัญหา ตัดสินใจ เลือกใช้เครื่องมือ และลงมือทำงานเพื่อให้บรรลุเป้าหมายที่ได้รับ**

คำสำคัญมีทั้งหมด 5 คำ

- Goal
- Reasoning
- Planning
- Action
- Observation

# 2. Traditional Software vs AI Agent

## Traditional Software

โปรแกรมทั่วไปทำงานตามขั้นตอนที่นักพัฒนาเขียนไว้ล่วงหน้า

Input
↓
Business Logic
↓
Output

ตัวอย่าง

def add(a, b):
return a + b

ทุกอย่างถูกกำหนดไว้แล้ว

โปรแกรมไม่สามารถเปลี่ยนวิธีทำงานเองได้

---

## AI Agent

Agent ทำงานแตกต่างออกไป

Goal
↓
Think
↓
Plan
↓
Choose Action
↓
Execute
↓
Observe
↓
Goal Completed?

├── No → Repeat
└── Yes → Finish

Agent จะตัดสินใจเองว่า

> "ขั้นตอนต่อไปควรทำอะไร"

แทนที่จะทำตามลำดับที่กำหนดไว้ตายตัว

---

# 3. LLM vs AI Agent

หลายคนเข้าใจผิดว่า

ChatGPT = AI Agent

แต่จริง ๆ แล้ว

**ไม่ใช่**

LLM มีหน้าที่หลักคือ

Prompt
↓
LLM
↓
Generated Text

ในขณะที่ Agent ทำงานแบบนี้

Goal
↓
Agent
├── LLM
├── Memory
├── Planner
├── Runtime
├── Tools
└── Skills
↓
Completed Task

LLM เป็นเพียง "สมอง"

ส่วน Agent คือระบบทั้งหมด

---

## เปรียบเทียบ

| LLM                  | AI Agent             |
| -------------------- | -------------------- |
| สร้างข้อความ         | ทำงานให้สำเร็จ       |
| ตอบคำถาม             | ลงมือทำ              |
| ไม่มีการวางแผน       | วางแผนหลายขั้นตอนได้ |
| ไม่มีเครื่องมือ      | ใช้เครื่องมือได้     |
| ไม่มี Memory ระยะยาว | มี Memory และ State  |

---

# 4. ทำไม AI Agent ต้องมี Tools?

ลองคิดดูว่า

ผู้ใช้ถามว่า

> "ช่วยอ่านไฟล์ PDF ทั้งโฟลเดอร์ แล้วสร้างรายงาน Excel"

LLM เพียงอย่างเดียวไม่สามารถทำได้

แต่ Agent สามารถ

ค้นหาไฟล์
↓
เปิดไฟล์
↓
OCR (ถ้าจำเป็น)
↓
สรุปข้อมูล
↓
สร้าง Excel
↓
บันทึกไฟล์

สิ่งเหล่านี้เกิดขึ้นได้เพราะ Agent สามารถเรียกใช้ **Tools** ได้

ตัวอย่างของ Tools ได้แก่

- File System
- Database
- Browser
- REST API
- OCR
- Terminal

# 5. องค์ประกอบหลักของ AI Agent

ภาพรวมของ Agent

                   AI Agent
                       │
      ┌────────────────┼────────────────┐
      │                │                │
     LLM            Memory          Tools
      │                │                │
      └────────────────┼────────────────┘
                       │
                Decision Making
                       │
                 Execute Actions

หน้าที่ของแต่ละองค์ประกอบ

| Component | Responsibility               |
| --------- | ---------------------------- |
| LLM       | วิเคราะห์และให้เหตุผล        |
| Memory    | จดจำข้อมูล                   |
| Planner   | วางแผนการทำงาน               |
| Runtime   | ควบคุมลำดับการทำงาน          |
| Tools     | ติดต่อระบบภายนอก             |
| Skills    | ความสามารถเฉพาะด้านของ Agent |

# Summary

AI Agent คือวิวัฒนาการของระบบ AI จากเดิมที่สามารถ "สร้างข้อความ" ไปสู่ระบบที่สามารถ "ลงมือทำงาน" ได้จริง
โดยอาศัยการทำงานร่วมกันของ LLM, Memory, Planning, Runtime และ Tools
การเข้าใจพื้นฐานเหล่านี้ จะช่วยให้เราเข้าใจหัวข้อขั้นสูง เช่น Tool Calling, Private Skills, Runtime และ Agent Architecture ได้ง่ายขึ้น
